# Node Express API

Project nay tach rieng khoi `DemoWebApi` de ban hoc/so sanh voi phien ban C#.

## Chay project

```powershell
cd node-express-api
npm install
npm start
```

Mac dinh server chay o `http://localhost:3000`.

## API chinh

- `GET /api/hello`
- `GET /api/hello/:name`
- `POST /api/hello`
- `GET /api/students`
- `GET /api/students/:id`
- `POST /api/students`
- `PUT /api/students/:id`
- `DELETE /api/students/:id`
